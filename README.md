# DVY-Bot
My second ever project, a more "mature" (in my opinion) showcase of my experience and skills than [8-Bit](https://github.com/Bimi05/8-Bit).

This bot was a discord bot I made catered specifically for a brawl stars community server I was in titled "Diversity", around 2021-2022!

## What does it do?
It is what you'd expect. A server bot. It handled our verification system by assigning the right club (and, optionally, stat) discord roles, as well as handling various admin tasks (such as a staff roster overview, a community suggestion forwarding mechanic)

## What I learned
I didn't learn anything new regarding to coding in particular, but granted the environment this was made in, I learnt to:
- Meet deadlines
- Deliver qualitative results
- Ensure what I delivered fell in line with the format the staff were expected to use
- Be quick and accurate with bug fixes
